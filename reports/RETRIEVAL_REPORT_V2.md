## 8. `last_injection` — structured lookup, NOT a retrieval benchmark

- Prime only; source OCT-DR `Data` sheet. 580 eligible current visits; 580 have a prior injected visit. When one exists, the latest prior visit is that visit in 50.9% of cases.
- Injection status is not in the retriever memory, so no retrieval metrics are reported. With the field in memory the answer is a deterministic lookup.

## 9. v1 results relabelled

The v1 report's 1.000 scores for `combined` and `rule_router` are **pipeline checks**: those strategies implement the same rules that define the v1 ground truth. They are not evidence that question-aware retrieval is better. v1 outputs are preserved unchanged in `results/v1_snapshot/` (checksums verified), and the test suite reproduces the v1 test-split metrics exactly.

## 10. Deviations from the spec

- None in definitions, eligibility, tie handling or splits. Counts match spec §4 exactly (`test_v2_counts_match_spec`).
- Added beyond the spec: `h_*` fixed heuristics run as strategies (the spec's heuristic ceiling was computed analytically). They use CST/BCVA/order only.
- The v1 report text was relabelled (pipeline-check wording); v1 metrics and files are unchanged.

## 11. Limitations

- Prime-only types (`one_year_ago`, `six_months_ago`, `max_leakage`) have 7–8 test patients, so their CIs are wide.
- The leakage index is an angiography measure, not OCT. Failure to retrieve it from CST/BCVA/time does not show that OCT images would or would not find it.
- Tier-B ground truth comes from the same CST/BCVA/order data the retrievers see. A future retriever that implements these rules would score ~1.0 by construction; such results must be reported as rule coverage.
- The independent paraphrases were written by another instance of the same model family, not by clinicians. They reduce, but do not remove, parser-test leakage.
- The fixed-heuristic ceiling is chosen on the evaluation data itself, so it is an optimistic reference.
- No abstention mechanism exists yet, so IE questions are not handled by any strategy.
